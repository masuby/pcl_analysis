# Sales Review Report - User Guide

## Quick Start

### Accessing the Report

1. **Navigate to Dashboard**
   - Click on "Dashboard" in the main navigation
   - Select "Departmental Dashboard" from the tabs

2. **Open Sales Review Report**
   - Look for the navigation buttons at the top
   - Click on "SALES REVIEW REPORT" (second button, right after "SCORE CARD REPORTS")

   ```
   [SCORE CARD REPORTS] [SALES REVIEW REPORT] [GAP ANALYSIS] [PENETRATION ANALYSIS] [SETTLEMENTS ANALYSIS]
                              ↑
                         Click here!
   ```

3. **View the Report**
   - The report will load with the latest management data
   - Scroll down to see all sections

## Report Sections

### 1. Key Performance Metrics
📊 **What you'll see:**
- 8 colorful metric cards showing critical KPIs
- Real-time values from latest data
- Percentage calculations where applicable

**Metrics included:**
- Total Disbursements
- Active Clients
- Portfolio Outstanding
- Active Loans
- PAR > 30 Days (with portfolio percentage)
- New Business (with disbursement percentage)
- Repeat Business (with disbursement percentage)
- Portfolio Quality ratio

### 2. Performance Overview
📈 **What you'll see:**
- Three interactive charts showing trends over time
- Last 12 months of data

**Charts included:**
1. **Monthly Disbursements Trend** - Bar chart showing lending activity
2. **Portfolio Growth Trend** - Line chart tracking portfolio changes
3. **Active Clients & Loans** - Multi-line chart comparing client and loan growth

**How to use:**
- Hover over chart elements to see exact values
- Charts update automatically when new data is uploaded

### 3. Branch-wise Performance Analysis
🏢 **What you'll see:**
- Dropdown to select different metrics
- Main branches comparison chart
- Sub-branch breakdowns for CS and LBF
- Performance summary table with percentages

**Available metrics:**
- Disbursements This Month
- Portfolio
- Active Reps
- Number of loans
- PAR>30
- New Business
- Repeat Business

**How to use:**
1. Select a metric from the dropdown
2. View the main branches bar chart
3. Scroll down to see CS and LBF sub-branches
4. Check the summary table for percentage contributions

### 4. Trend Analysis & Insights
📊 **What you'll see:**
- Period comparison (latest vs previous)
- 7 trend cards showing changes
- AI-generated insights and recommendations
- Color-coded indicators (green = positive, red = negative, orange = warning)

**Insights include:**
- Growth alerts (when changes > 10%)
- Portfolio quality warnings
- Business mix analysis
- Client base trends

## Generating PowerPoint

### Steps to Generate PPTX

1. **Select Review Period**
   - Click on the month selector at the top right
   - Choose the month you want to report on
   - Format: YYYY-MM (e.g., 2026-02)

2. **Generate Report**
   - Click the green "Generate PowerPoint" button
   - Wait for the generation process (usually 2-5 seconds)
   - Button will show "Generating..." during processing

3. **Download**
   - File will automatically download to your browser's default download location
   - File name format: `Sales_Review_YYYY-MM.pptx`

### PowerPoint Contents

The generated PPTX includes 8 professional slides:

1. **Title Slide**
   - Report title
   - Selected month
   - Generation date

2. **Executive Summary**
   - Complete KPI table
   - All 8 key metrics with details

3. **Disbursements Analysis**
   - 12-month bar chart
   - Visual trend analysis

4. **Branch Performance Comparison**
   - Table comparing all branches
   - Disbursements, Portfolio, Clients, Loans

5. **Portfolio Quality Analysis**
   - PAR > 30 ratio
   - Quality status indicator
   - Detailed breakdown table

6. **Business Mix Analysis**
   - Pie chart: New vs Repeat Business
   - Percentage breakdown

7. **Conclusions & Recommendations**
   - AI-generated insights
   - Numbered list of findings
   - Action recommendations

8. **Thank You Slide**
   - Contact information
   - PCL branding

## Data Requirements

### Minimum Requirements
- At least 1 management report uploaded
- Report must contain country-wide data

### Optimal Requirements
- Multiple management reports for trend analysis
- Data from multiple branches
- Historical data (12 months recommended)

### If Data is Missing
- Empty sections will show "No data available"
- Charts may show fewer data points
- Trends require at least 2 data points

## Troubleshooting

### Report Not Loading
**Problem**: Blank screen or loading forever
**Solution**: 
- Check if management reports are uploaded
- Refresh the page
- Check browser console for errors

### Charts Not Displaying
**Problem**: Missing or broken charts
**Solution**:
- Ensure data is available for the selected period
- Try selecting a different metric
- Clear browser cache and reload

### PPTX Generation Fails
**Problem**: Button shows error or nothing downloads
**Solution**:
- Check browser popup settings
- Verify data is loaded
- Try a different month
- Check browser console for specific error

### Missing Data in Report
**Problem**: Some sections show "No data available"
**Solution**:
- Upload more management reports
- Verify report data includes all branches
- Check date range of available data

### Incorrect Values
**Problem**: Numbers don't match expectations
**Solution**:
- Verify source data in Management Dashboard
- Check date filters
- Ensure latest reports are uploaded
- Contact system administrator

## Frequently Asked Questions

### Q: How often should I generate reports?
**A:** Monthly is recommended, at the end of each month when all data is available.

### Q: Can I customize the PowerPoint template?
**A:** Currently, the template is fixed. Contact the development team for customization requests.

### Q: What's the difference between this and Score Card Reports?
**A:** Score Card focuses on individual department KPIs. Sales Review provides comprehensive analysis across all branches with Management Dashboard data.

### Q: How far back does the data go?
**A:** The report shows all available data, typically limited by what's uploaded in the Management Dashboard.

### Q: Can I email the report directly from here?
**A:** Not yet - this feature is planned for a future update. Currently, download the PPTX and email manually.

### Q: Do the insights update automatically?
**A:** Yes! Insights are generated in real-time based on current data patterns and trends.

### Q: Can I export to PDF instead of PowerPoint?
**A:** Not currently supported, but it's on the roadmap for future releases.
